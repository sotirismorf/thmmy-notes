## Ιούνιος 2024

### 1. Ποια ομάδα παιδιών έχει δυσκολία στην ανάπτυξή της Θεωρίας του Νου;

- [ ] Α. Όσα παιδιά εξωτερικεύουν τον θυμό τους
- [x] Β. Τα παιδιά με διαταραχή στο φάσμα του αυτισμού
- [ ] Γ. Όσα παιδιά άργησαν να πάνε στο σχολείο
- [ ] Δ. Όσα παιδιά εσωτερικεύουν τα συναισθήματά τους

### 2. Τι είναι σωστό ως προς την κατάθλιψη;

- [ ] Α. Στις διαταραχές εσωτερίκευσης έχει χαμηλή πιθανότητα επανεμφάνισης
- [ ] Β. Στην κατάθλιψη δεν υπάρχουν αυτοκτονικοί ιδεασμοί
- [ ] Γ. Η κατάθλιψη δεν έχει γενετικό υπόβαθρο
- [x] Δ. Τα άτομα με κατάθλιψη παρουσιάζουν υπερενεργοποίηση της αμυγδαλής σε αρνητικά γεγονότα

### 3. Ένας τρόπος ενίσχυσης συμμαχιών στα πρωτεύοντα θηλαστικά είναι μέσω:

- [ ] Α. Της προσκόλλησης
- [ ] Β. Της εχθρικότητας
- [ ] Γ. Του άλφα αρσενικού
- [x] Δ. Της περιποίησης

### 4. Όταν ένα παιδί κατακτήσει την ικανότητα αυτοαναγνώρισης τότε μπορεί να εκδηλώσει:

- [ ] Α. Λιγότερο αμοιβαία βλεμματική επαφή
- [ ] Β. Δυσκολία στην ανίχνευση ψεύδους
- [ ] Γ. Φόβο
- [x] Δ. Αμηχανία

### 5. Η αμυγδαλή και η νήσος:

- [ ] Α. Είναι μέρη των βασικών γαγγλίων
- [x] Β. Εμπλέκονται στην επίγνωση του εαυτού
- [ ] Γ. Εμπλέκονται στις αρνητικές μνήμες
- [ ] Δ. Είναι μέρη των κροταφικών λοβών

### 6. Για να επιτευχθεί η ρυθμιστική λειτουργία του συναισθήματος θα πρέπει:

- [ ] Α. Το παιδί να μπορεί να αυτορυθμίζεται
- [ ] Β. Το μωρό να επηρεάζεται από τις αντιδράσεις των γονέων
- [x] Γ. Οι γονείς να επηρεάζονται από τις αντιδράσεις του μωρού
- [ ] Δ. Το παιδί να αναπτύξει δεσμό με τον εαυτό του

### 7. Σύμφωνα με τη θεωρία των βιολογικών κινήτρων τα συναισθήματα προέκυψαν:

- [ ] Α. Για να διεκδικήσουμε τους συναισθηματικούς μας δεσμούς
- [ ] Β. Από την πίεση για κοινωνική ενσωμάτωση
- [x] Γ. Για να αναπαραχθούν τα γονίδιά μας
- [ ] Δ. Για να βοηθηθούμε στην προσκόλληση

### 8. Η ικανότητα ρύθμισης των συναισθημάτων:

- [ ] Α. Είναι έμφυτη
- [x] Β. Πρέπει να διδαχτεί από τον φροντιστή
- [ ] Γ. Είναι σημαντική για την ανάπτυξη της απορρύθμισης
- [ ] Δ. Δεν επηρεάζεται από την ηλικία

### 9. Ποια από τις παρακάτω περιοχές σχετίζεται με το αίσθημα του πόνου:

### 14. Ποιες περιοχές σχετίζονται με κάποιο τρόπο με την ανταμοιβή:

- [ ] Α. Ο επικλινής πυρήνας και ο πρόσθιος λοβός
- [x] Β. Ο επικλινής πυρήνας και η αμυγδαλή
- [ ] Γ. Το ραβδωτό σώμα και η νήσος
- [ ] Δ. Η νήσος και ο μεσοκοιλιακός προμετωπιαίος φλοιός

### 19. Ποιο συναίσθημα αναγνωρίζουμε καλύτερα μέσω του αγγίγματος:
